## A different way to make games

<div class="features-grid">

<a href="/features#design" class="feature-link" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/innovative.webp" style="background:linear-gradient(90deg,#333747 11%,#2d3342 50%,#2d3342 68%,#272d3c 87%)" loading="lazy" width="1" height="1" />

<div class="body">

#### Innovative design

Godot's Node and Scene system gives you both power and flexibility to create anything.

</div>

</div>

<a href="/features#script" class="feature-link" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/language.webp" style="background:linear-gradient(90deg,#252a35 46%,#252a35 53%,#202630 76%,#202630 89%)" loading="lazy" width="1" height="1" />

<div class="body">

#### Use the right language for the job

Keep your code modular with an object-oriented API using Godot's own GDScript, C#, C++, or bring your own using GDExtension.

<div style="margin-top:.5rem;font-size:.875rem;line-height:1.6;opacity:.8">

C# support is currently only available for desktop and mobile platforms as of Godot 4.2.  
Use Godot 3 to run C# on the Web platform.

</div>

</div>

</div>

<a href="/features#features_2d" class="feature-link" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/2d.webp" style="background:linear-gradient(90deg,#196f36 7%,#28674e 29%,#2a4b46 65%,#3b6f4e 97%)" loading="lazy" width="1" height="1" />

<div class="body">

#### Dedicated 2D engine

Make crisp and performant 2D games with Godot's dedicated 2D rendering engine with real 2D pixel coordinates and 2D nodes.

</div>

</div>

<a href="/features#features_3d" class="feature-link" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/3d.webp" title="Screenshot from the game &#39;Human Diaspora&#39;" style="background:linear-gradient(90deg,#196f36 7%,#28674e 29%,#2a4b46 65%,#3b6f4e 97%)" loading="lazy" width="1" height="1" />

<div class="body">

#### Simple and powerful 3D

Godot's 3D nodes give you everything you need to build, animate, and render your 3D worlds and characters.

</div>

</div>

<a href="/features#features_xr" class="feature-link" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/xr.webp" title="Screenshot from the game &#39;Penguin Festival&#39;" style="background:linear-gradient(90deg,#196f36 7%,#28674e 29%,#2a4b46 65%,#3b6f4e 97%)" loading="lazy" width="1" height="1" />

<div class="body">

#### Exemplary XR support

Godot has built-in support for OpenXR and WebXR, and supports various other XR SDKs through plugins.

</div>

</div>

<a href="/features#deploy" class="feature-link" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/cross-platform.svg" style="background-color:#333667" loading="lazy" width="1" height="1" />

<div class="body">

#### Release on all platforms

Deploy your game on desktop, mobile, and the web in seconds. Godot even supports consoles through third party publishers.

</div>

</div>

<a href="#get_involved" class="feature-link feature-link--open-source" data-barba-prevent=""></a>

<div class="feature dark">

<img src="/assets/home/features/oss.svg" style="background-color:#333667" loading="lazy" width="1" height="1" />

<div class="body">

#### Open Source

Truly open development: anyone who contributes to Godot benefits equally from others’ contributions.

</div>

</div>

## Get involved

Join the community and help create a game engine that belongs to everybody.

<div class="flex eqsize responsive">

<div class="text-center base-padding">

<img src="/assets/home/code.svg" loading="lazy" width="250" height="250" />

#### Code

If you know how to code, you can help by fixing bugs and working with engine contributors towards the implementation of new features.

<a href="https://contributing.godotengine.org/en/latest/ways_to_contribute/development.html#contribute-engine-code" class="btn btn-flat btn-flat-frosted" target="_blank" rel="noopener">Learn more</a>

</div>

<div class="text-center base-padding">

<img src="/assets/home/document.svg" loading="lazy" width="250" height="250" />

#### Document

Documentation quality is essential in a game engine; help make it better by updating the API reference, writing new guides or submitting corrections.

<a href="https://contributing.godotengine.org/en/latest/ways_to_contribute/development.html#contribute-documentation" class="btn btn-flat btn-flat-frosted" target="_blank" rel="noopener">Learn more</a>

</div>

<div class="text-center base-padding">

<img src="/assets/home/report.svg" loading="lazy" width="250" height="250" />

#### Report

Found a problem with the engine? Don't forget to report it so that developers can track it down.

<a href="https://contributing.godotengine.org/en/latest/ways_to_contribute/feedback.html" class="btn btn-flat btn-flat-frosted" target="_blank" rel="noopener">Learn more</a>

</div>
