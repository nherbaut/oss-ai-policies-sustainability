<div class="field__item even">

EFF needs a few good volunteers. With many important technology projects in the works and a limited amount of staff and time, we are always looking for volunteers with the skills to help us support the open source projects that we run.

If you are a designer, programmer, security auditor, QA person, or have other skills to contribute, we are happy to have your help. Some ways you can help include: improving design, improving usability, fixing bugs, reporting bugs, finding security issues, fixing security issues, writing tests, adding new features, translating interfaces or helping with whatever needs to get done.

## **<span id="ai-policy"></span>Policy Regarding AI-Assisted Contributions**

We are a team of humans that are glad to help other humans get experience so they can better contribute to our open source projects. However, when people use AI to write code, submit pull requests, and interact with reviewers, that experience is not being built. While we’re open to accepting AI-generated code, we cannot prioritize reviewing generated code for the sake of building community in the same way we would with human-authored contributions. Therefore, we are forced to be much more stringent about our community interactions when AI is used to author code. If we wanted to use generative AI to simply get the code written, we would use our own internal resources to do so, and skip the extra step of reviewing prompted code from external sources.  
  
**Going forward, AI-assisted contributions will need to follow the conditions below.**

**Your Submissions will be Deprioritized If:**

- It isn’t in the team’s projected work plan.
- Multiple pull requests submitted in a short cycle.
- Unread and ignored contribution and pull request checklists.
- Pull requests that are too large for a single human to review in a reasonable amount of time (~400 loc).

**AI-Assisted Guidelines**

- You must explicitly disclose if your contribution was AI-generated or AI-assisted.
- All contributions must be thoroughly understood, reviewed, and tested by you.
- All commit descriptions and comments must be written by you.
- All further changes and modifications must be understood and handled by you, not a generated answer for our feedback.
- Do not respond to our questions or requests with the output of your AI coding tools; **we took the time to have a human craft a response to you, please extend us the same courtesy**.
- You must fill out issues yourself; do not auto generate issues.
- You must submit feature requests based on your own understanding, and be able to properly articulate and explain what it is you are asking for.

**AI-Generated Security Reports**

- Fully auto-generated security reports must be reviewed, tested, and confirmed by a human before submission.
- Submissions must follow the vulnerability and software support policy listed in the project.

## **<span style="box-sizing: border-box;">Security Reporting</span>**

For more information (including instructions on how to notify us of security vulnerabilities), see our [Security Vulnerability Disclosure Program](/security).
