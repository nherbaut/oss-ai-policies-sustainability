# Potential technical problems in the collected data

Audit date: 2026-11-05. This is a manual repair checklist based on the files currently on disk, dataset URL cells, and saved retrieval manifests. Pending/fixed status was reviewed on 2026-11-05. URLs below are recorded originals, not newly checked live URLs. Only unresolved issues appear under **Pending**. An issue moves to **Fixed** when a usable replacement is available, even if the original missing slot, stub, HTML download, or failed capture is retained for history. A replacement at another revision is identified in the original audit notes; it is not an assertion of byte-identical recovery.

Scope: both `data/281/policies` and `data/92/policies`, plus supplementary sources referenced by the corpus and pilot manifests. Raw companions are grouped with their extracts. Frozen evidence copies, QualCoder imports, CSV backups, and ordinary duplicate policy texts are not repeated. Missing files are explicitly marked; their paths are expected download slots rather than existing files.

Checks covered blank/whitespace-only content, UTF-8 decoding failures, suspicious encoding/control characters, HTML saved as Markdown, bot/access/browser error pages, redirect notices, path stubs, unexpanded templates, missing linked files, and recorded download failures. All scanned text decoded as UTF-8; no general decoding failure was found. The replacement characters in ripgrep's FAQ and difftastic's changelog are intentional examples/discussion of invalid UTF-8, so they are not flagged as damage. Short valid documents and agent directives whose target exists locally are not flagged merely for being short. This heuristic audit cannot guarantee that every page is complete or correctly rendered.

For missing multi-URL slots, each recorded URL is listed. For repository companion files in `data/92`, source URLs are reconstructed from the repository, pinned commit and filename in `policies-pin-report.json`; legacy HTML URLs come directly from embedded `og:url` metadata. Forgejo’s contributing URL was supplied in this checklist and is now recorded in the dataset.
